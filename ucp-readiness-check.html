What it checks

The first buyer-agent pass is mostly a discovery problem.

Before a merchant debates deep integration work, the public surface should already tell an agent what is sold, how products are identified, what policies apply, where checkout context begins, and where machine-readable documentation lives.

ucp

Protocol discovery

Looks for UCP profile hints, agent docs, llms.txt, agents.md, robots, sitemap, and other surfaces that help agents map the store without guessing.

catalog

Product and offer facts

Searches public content for product schema, offer language, variants, availability, price, merchant identity, and structured commerce markers.

policy

Shipping and returns

Flags whether shipping, return, refund, cancellation, and support context are visible enough for an agent-mediated buyer path.

handoff

Checkout boundary

Does not touch checkout. It checks whether public copy and discovery files make the cart, checkout, payment, receipt, and support boundaries legible.
