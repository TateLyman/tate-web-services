# Close Kit

Updated: 2026-05-07.

## Reply Handling

### Positive or curious reply

Use this when a business asks what the repair pass includes, what it costs, or how it works.

```text
Thanks for replying.

The smallest useful scope is the fixed $150 repair pass:

- mobile layout/contact flow check
- page title/meta cleanup
- obvious image speed cleanup
- broken link/button check
- short FAQ or proof-section recommendation
- before/after checklist

Timeline is usually 2-3 days once I have the needed site access or files. If the site builder makes something impossible, I will flag it before changing scope.

If you want to start, send:

1. the site login or editable files
2. the main action you want visitors to take
3. any brand photos/reviews you want used

I can send a fixed scope before touching anything.
```

### Price objection

```text
That makes sense. I can keep it smaller.

For $75 I can do a diagnostic pass only: mobile/contact check, screenshots, and a prioritized fix list. If you want me to implement the fixes after that, the $75 can count toward the $150 repair pass.
```

### Wants a full rebuild

```text
A full one-page rebuild starts at $350 if the scope is simple: home page, service sections, proof/reviews, FAQ, contact buttons, mobile layout, and launch-ready files.

The fastest path is still to start with the $150 repair pass unless the current site is too hard to edit. That keeps the first project low-risk and gives us a clear before/after.
```

### After a repair pass is accepted

Use this after the client says yes to the first project.

```text
After the repair pass, there is an optional monthly care plan if you want small edits and checks handled without starting a new project each time.

The smallest plan is $49/mo for minor edits, contact-flow checks, and a monthly note. Details are here:

https://tatelyman.github.io/tate-web-services/maintenance.html

No need to decide that now. The first step is just the repair pass.
```

### Agency reply

```text
Thanks for replying.

The easiest way to test fit is one scoped task: a landing page section, mobile cleanup pass, content migration, QA sweep, or small static page.

Send the task, stack, deadline, and whether you prefer fixed price or hourly. I will reply with timing, assumptions, and a short quote before starting.
```

## Payment And Delivery

For a first client with no established trust, avoid unpaid large work.

- Best: 50% before implementation, 50% before launch/handoff.
- Acceptable for first tiny job: build a private preview first, then collect payment before handing over editable files or production changes.
- Avoid: doing a full rebuild before payment.

## Follow-Up Rules

- Business repair-pass leads: no follow-up before 2026-05-12.

- If someone replies "no" or asks not to follow up, mark `opted_out` and do not contact again.
